## What This Is
A classic Snake game built with vanilla JavaScript. Clean design, smooth controls, mobile-ready.

## What's Inside
- 🎮 **Classic gameplay** - Eat food, grow longer, don't hit walls or yourself
- 📱 **Mobile-friendly** - Touch controls for on-the-go play
- ⚡ **Three speeds** - Easy, Medium, Hard
- ⏸️ **Pause/Resume** - Take breaks anytime
- 🏆 **High Scores** - Local storage saves your best
- ⏱️ **Game timer** - Track how long you survive

## Controls
**Keyboard:** Arrow keys  
**Mobile:** On-screen buttons  
**Mouse:** Pause/Play button

## Tech Stuff
- Pure JavaScript (no frameworks)
- CSS Grid for the game board
- LocalStorage for scores
- Responsive design

## Try It
https://snake-game-s.netlify.app
Or clone and open `index.html` in your browser.

## Why I Built This
Wanted to see if I could make the classic game feel good on both desktop and phone. Learned a lot about game loops and collision detection along the way.
